# PowerGateway 1.4.0-dev

## Schwerpunkt

Phase 1 der hochauflösenden Energieerfassung stellt die lokale Messwerthistorie auf einen dauerhaft laufenden Sammler um.

## Neu

- Standard-Erfassungsintervall von 30 Sekunden
- konfigurierbare Intervalle von 5, 10, 30 oder 60 Sekunden
- Einstellung direkt im Energie-Dashboard
- Speicherung jedes Erfassungszeitpunkts als eigener Rohdatensatz
- keine Vorverdichtung beim Speichern
- Verdichtung erfolgt erst bei der Abfrage für die Grafik
- Statusdatei unter `/var/lib/powergateway/energy_collector_state.json`
- sofortige Übernahme eines geänderten Intervalls ohne Dienstneustart
- sauberer Stopp über SIGTERM und SIGINT
- automatischer Neustart des Sammlers über systemd

## Technische Änderung

`powergateway-energy-history.service` ist kein One-shot-Dienst mehr. Der Dienst startet `energy_history_runner.py --daemon` und bleibt dauerhaft aktiv. Das verhindert den wiederholten Start eines neuen Python-Prozesses für jeden Messpunkt.

## Datenhaltung

Die Rohdaten werden weiterhin in folgender SQLite-Datenbank gespeichert:

```text
/var/lib/powergateway/energy_history.sqlite3
```

Bei 30 Sekunden entstehen maximal 2.880 Messpunkte pro Tag. Die vorhandene SQLite-Konfiguration mit WAL-Modus und Zeitstempelindex bleibt erhalten.

## Prüfung nach Installation

```bash
cat /opt/powergateway/version.txt
sudo systemctl status powergateway-energy-history.service --no-pager -l
sudo journalctl -u powergateway-energy-history.service -n 50 --no-pager
cat /var/lib/powergateway/energy_collector_state.json
```

Im Energie-Dashboard kann das Intervall unter **Messwerterfassung** geändert werden.
