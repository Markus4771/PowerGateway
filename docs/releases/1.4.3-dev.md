# PowerGateway 1.4.3-dev

## Schwerpunkt

Phase 3 erweitert das Energie-Dashboard um Verbrauchsprofile und Vergleiche mit dem jeweiligen Vorzeitraum.

## Neu

- Tagesprofil: Heute gegenüber Gestern
- Wochenprofil: Diese Woche gegenüber Vorwoche
- Monatsprofil: Dieser Monat gegenüber Vormonat
- Jahresprofil: Dieses Jahr gegenüber Vorjahr
- gruppierte Verbrauchsbalken für aktuellen Zeitraum und Vorzeitraum
- Kennzahlen für Verbrauch, Veränderung, Kosten, Lastspitze und Messpunkte
- Verbrauchsberechnung bevorzugt aus Zählerständen
- Fallback-Berechnung durch zeitliche Integration der Leistungskurve
- responsive Darstellung ohne externe Diagrammbibliothek
- neue interne Schnittstelle `/_internal/energy/analysis`

## Hinweise

Aussagekräftige Vergleiche setzen voraus, dass für den Vorzeitraum bereits genügend Messwerte in der lokalen SQLite-Datenbank vorhanden sind. Bei fehlender Vergleichsbasis wird keine prozentuale Veränderung berechnet.

## Test

1. Energie-Dashboard öffnen.
2. Tages-, Wochen-, Monats- und Jahresprofil nacheinander auswählen.
3. Balken, Summen, Kosten und Veränderung prüfen.
4. Zeiträume mit noch unvollständiger Historie auf verständliche Darstellung prüfen.
